OpenAPI Schemas & Specifications

  • ChainForge API Reference Guide chainforge-api-reference-guide

    The ChainForge API Reference Guide is a lookup document covering every REST endpoint across sixteen chapters. It explains authentication, scopes, pagination, idempotency, rate limits and finality, then documents accounts, transactions, gas, contracts, tokens, webhooks, usage and WebSocket subscriptions with parameters, examples and errors, plus schemas, error catalog and reference tables.

  • ChainForge YAML chainforge.yaml

    The chainforge.yaml file is an OpenAPI 3.0.3 specification describing the same API as the reference guide. It defines thirty-two paths, bearer and OAuth2 security, reusable parameters, responses and schemas, an error code enumeration and a webhook callback. It passes Redocly validation with six warnings, ready for rendering, mocking or linting.
